# DeFi Pulse Dashboard

DeFi protocol analytics dashboard showing Total Value Locked across 200+ protocols and chains

## Features

- Top 50 DeFi protocols by TVL with protocol icons
- Filter by category: Staking, Lending, DEX, Bridge
- Total TVL across all chains
- 1d / 7d / 1m price change tracking
- Chain distribution with badges
- Purple/pink gradient dark theme

## Tech Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI:** shadcn/ui + Tailwind CSS
- **Animations:** Framer Motion
- **API:** DeFi Llama API (Free, No API Key)
- **Deployment:** Vercel
